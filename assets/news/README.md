# News photos

Put photos for the News page in this folder, then list them in `data/news.json`
under the matching news item, for example:

    "images": [
      { "file": "2026-11-iit-kharagpur-1.jpg", "caption": "Seminar at IIT Kharagpur" }
    ]

Tips: use JPG or WebP, about 1600 px on the long side and under ~500 KB each.
File names: lowercase, no spaces (use hyphens).
